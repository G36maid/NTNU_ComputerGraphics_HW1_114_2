🖱️ How to Draw

  • Left Click on the canvas to draw the current shape with the current color.

📐 Change Shapes

  • Press 1 or P : Point
  • Press 2 or T : Triangle
  • Press 3 or C : Circle
  • Press 4 or S : Square

🎨 Change Colors

  • Press R : Red
  • Press G : Green
  • Press B : Blue
Rule Note:
Only the last 3 shapes of each type will be kept on the screen. Single gl.drawArrays() per shape type is implemented via VBO batch rendering.
